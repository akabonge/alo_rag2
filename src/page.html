            How this works
            1. Search runs on your device. BM25 keyword ranking over this site’s own content (about 57 sections). Instant, free, and it flies the camera to the best source.
            2. Grounding check. A section must match at least half of your question’s key-word groups and enough terms known to the site, so one stray word (“white” in “White House”) can’t pull in the wrong answer.
            3. Claude writes the answer. Your question goes to a Vercel function, which independently retrieves up to 3 sections and calls Anthropic’s Claude API. The prompt asks it to use those sources, cite them like [1], and acknowledge missing information.
            4. Cost and abuse controls. The browser caches answers for the tab session. Warm server instances cache answers for up to 24 hours, while Redis applies a shared rolling limit of 8 valid attempts per IP per minute. Replies are capped at 220 tokens. The API key stays on the server.
            5. Fallback. If AI generation is unavailable, you still get matching sentences extracted from the source. Generated answers can make mistakes; check their cited sources.
